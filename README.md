# 📸 Style N&B

**ゲーム内のスマホで写真雑誌を作って売れる、FiveM 用のフォトマガジンアプリ**

</div>

GTA5 のロールプレイサーバー「GMC RP」向けに作った、ゲーム内スマホ（lb-phone）のアプリです。
ゲーム内でフォトグラファーの仕事（ジョブ）に就いているプレイヤーが写真雑誌を作り、ほかのプレイヤーはゲーム内のお金で雑誌を買って読めます。

GMC RP は約 2 年間、日本トップの人気を誇ったサーバーです。
このアプリのほかに、「新商品申請フォーム」や「ステッカー申請フォーム」などの Web アプリも作りました。

## 主な機能

| 機能 | 使う人 | 内容 |
| --- | --- | --- |
| 📚 **雑誌一覧** | 全プレイヤー | 表紙、タイトル、価格、購入済みかどうかを一覧で表示 |
| 💳 **購入** | 全プレイヤー | ゲーム内の銀行口座から代金を支払って雑誌を購入 |
| 📖 **閲覧** | 購入したプレイヤー | 写真とキャプションをページ順に読め、写真はタップで拡大 |
| ✏️ **作成・編集・削除** | フォトグラファー | タイトル、説明、表紙、価格、写真とキャプションを設定して雑誌を発行 |

## 工夫したところ

### ゲーム内の経済とつながる購入の仕組み

- 購入すると、プレイヤーの銀行口座から代金が引かれ、フォトグラファーの会社口座に入金されます
- 雑誌を売ることがそのままジョブの収入になるので、ロールプレイの動機になります
- 一度買った雑誌は何度でも読めて、同じ雑誌を二重に買うことはありません

### 不正を防ぐサーバー側のチェック

- 価格はクライアントから送られた値を使わず、必ずデータベースの値で支払い処理をしています
- 雑誌の作成・編集・削除は、サーバー側でフォトグラファーのジョブかどうかを確認してから実行します

### 公開・非公開と購入パスワード

- 雑誌ごとに「公開」「非公開」を切り替えられます。非公開の雑誌はフォトグラファーにしか表示されないので、発行前の下書きとして使えます
- 購入パスワードを設定すると、パスワードを知っている人だけが買えます。特定のお客さんだけに売る限定号などに使えます

### スマホアプリらしい UI

ゲーム内スマホの画面に収まるように、React で一覧・閲覧・編集の画面を作りました。
写真はタップで全画面表示でき、購入前には確認ダイアログを出して誤操作を防いでいます。

## 技術スタック

| | |
| --- | --- |
| **UI** | React 18, Vite, Tailwind CSS |
| **Game** | FiveM（Lua）, QBCore, lb-phone |
| **Database** | MySQL（oxmysql） |
| **Payment** | QBCore の銀行口座, okokBanking（会社口座への入金） |

```
lb-phone（ゲーム内スマホ）
   └─ Style N&B（React UI）
          │  NUI コールバック
          ▼
     client.lua ──▶ server.lua ──▶ MySQL（雑誌・写真・購入記録）
                        │
                        ├─ QBCore：ジョブの確認、代金の引き落とし
                        └─ okokBanking：フォトグラファーの会社口座へ入金
```

## ディレクトリ構成

```
.
├── fxmanifest.lua   # FiveM リソースの設定
├── client.lua       # lb-phone へのアプリ登録、UI とサーバーの橋渡し
├── server.lua       # 雑誌の取得・作成・更新・削除、購入処理
├── database.sql     # テーブル定義（雑誌、写真、購入記録）
└── ui/              # React アプリ（一覧、閲覧、購入、編集の画面）
```
